========================================
PERSONAL MINI-TOOLKIT — PROJECT PLAN
========================================

1. SELECTED TOOLS & DESCRIPTIONS
- Tool 1: To-Do List Manager — Allows the user to add, view, and remove tasks from a personal list during their session.
- Tool 2: Number Guessing Game — Challenges the user to guess a randomly generated number between 1 and 20 with high/low hints.
- Tool 3: Simple Calculator — Performs basic addition, subtraction, multiplication, or division on two numbers entered by the user.
